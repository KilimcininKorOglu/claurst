# mikmik

**Open-source, multi-provider terminal coding agent built in Rust.**

[![Version](https://img.shields.io/npm/v/mikmik?style=flat-square)](https://www.npmjs.com/package/mikmik)
[![License](https://img.shields.io/badge/License-GPL--3.0-blue?style=flat-square)](https://github.com/KilimcininKorOglu/mikmik/blob/main/LICENSE.md)

## Install

```bash
npm install -g mikmik
```

```bash
bun install -g mikmik
```

On install, the correct pre-built native binary for your platform is automatically downloaded from [GitHub Releases](https://github.com/KilimcininKorOglu/mikmik/releases). No compilation required.

## Usage

```bash
mikmik                    # interactive TUI
mikmik -p "fix this bug"  # headless one-shot
```

## Supported platforms

| Platform | Architecture |
|----------|-------------|
| macOS    | x64, arm64 (Apple Silicon) |
| Linux    | x64, arm64 |
| Windows  | x64 |
